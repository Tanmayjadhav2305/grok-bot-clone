# Bot Computer Slice 1 Implementation Plan

> **For agentic workers:** Execute task-by-task. Steps use checkbox syntax.

**Goal:** Runnable local-first Electron app with chat (OpenAI-compatible), MCP stdio host, tool permissions, and persisted settings.

**Architecture:** npm workspaces; Electron main owns agent-runtime + mcp-host + permissions + settings; preload exposes `window.bot`; React renderer via Vite.

**Tech Stack:** Electron 33+, TypeScript, React 19, Vite, Zod, Vitest, `@modelcontextprotocol/sdk`

---

## File map

| Path | Responsibility |
|------|----------------|
| `package.json` | Workspaces root |
| `packages/contracts/` | Settings + IPC event Zod schemas |
| `packages/permissions/` | allow once / always / deny |
| `packages/mcp-host/` | stdio MCP client lifecycle |
| `packages/agent-runtime/` | LLM stream + tool loop |
| `apps/desktop/` | Electron main, preload, Vite renderer |
| `apps/fixture-mcp/` | Tiny echo MCP server for tests/demo |
| `docs/evidence/slice1.md` | Evidence ledger |

---

### Task 1: Workspace + contracts

- Create root `package.json`, `tsconfig.base.json`, `packages/contracts`
- Settings schema + `toolKey(serverId, toolName)` + stream event types
- Vitest for schema parse

### Task 2: Permissions package

- Evaluate alwaysAllow; pending request map for UI gate
- Unit tests

### Task 3: Fixture MCP + mcp-host

- `apps/fixture-mcp` echo tool via MCP SDK stdio
- `McpHost` start/stop/listTools/callTool
- Integration test against fixture

### Task 4: Agent runtime

- OpenAI-compatible chat completions (streaming SSE or non-stream fallback)
- Tool loop with permission callback
- Unit test with mock fetch + mock tools

### Task 5: Electron desktop shell

- Main: settings store in `userData`, IPC handlers, wire runtime
- Preload: `contextBridge` → `window.bot`
- Renderer: chat, settings, permission modal
- `npm start` launches app

### Task 6: Evidence doc + README

- `docs/evidence/slice1.md`, root README (MIT, local-first, independent product)
